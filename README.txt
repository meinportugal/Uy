UY — 27 проектов Cordón / Montevideo
Дата проверки: 6 ноября 2026 года. Реестр ANV: 30 сентября 2026 года.

Откройте index.html двойным щелчком в современном браузере.
При распаковке ZIP сохраните рядом папки assets и sources.
Страница, фильтры, карта и маркеры работают локально без установки и без интернета.
Публичные сайты, объявления и официальные ссылки требуют подключения к интернету.
Карта содержит сохранённый снимок одного участка OpenStreetMap; при увеличении фон может выглядеть размытым.
Статическая карта: assets/map-static.svg. Номера совпадают с каталогом.
JSON: projects.json и anv-evidence.json. sources/ANV-2026-09-30.xlsx — исходный официальный реестр.

25 уникальных проектов восстановлены из исходного чата. Miraf Haedo 3 не дублируется.
Добавлены Nostrum Uruguay Centro и Tres Cruces Plaza. Статус всех трёх подтверждён по ANV.
Для каждого проекта отдельно показаны публичные коммерческие данные, статус программы и ограничения налоговой проверки.
Индивидуальное 100%-ное освобождение конкретной квартиры каталог не удостоверяет.
Цены, доступность, точную дату передачи и возможность купить гараж вместе с квартирой подтверждает продавец.
Цены гаражей, не найденные повторно, и неперепроверенные сроки явно помечены.
